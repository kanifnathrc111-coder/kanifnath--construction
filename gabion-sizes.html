Gabion Box Sizes & Specifications

Gabion dimensions and technical details should be confirmed against the bill of quantities or design drawings. Use this guide to prepare a complete enquiry—not as a substitute for the project specification.

Request a Quote Contact the Team

Dimensions are only the starting point

A gabion is usually described by length, width and height. Multiple sizes may be used on the same project. Confirm whether dimensions refer to the finished basket or the nominal supplied unit, and check any allowed dimensional tolerances.

Mesh and wire details

The mesh opening, wire diameter, wire tensile requirements, edge wire, lacing wire and any specified coating influence product suitability and cost. Terms like GI, zinc-coated, PVC-coated or double-twisted describe different details; request a proper technical data sheet when required.

How to submit dimensions

Use one consistent unit system and show the quantity for each size. For example, list each row as length × width × height, unit, quantity, mesh, wire/coating specification and remarks. Attach drawings when there are non-standard panels, stepped walls or site-specific arrangements.

Quotation checklist

  • Attach a BOQ or approved technical specification
  • List each size and quantity separately
  • Confirm coating and accessories
  • Ask for supply and installation prices separately
