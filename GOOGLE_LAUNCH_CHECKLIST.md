# Google & launch checklist

## Business truth and conversion
- [ ] Confirm legal / trading business name spelling.
- [ ] Confirm public phone, WhatsApp, email and actual operating base.
- [ ] Confirm which products are actually supplied (including PVC/GI options) and the exact specifications that may be quoted.
- [ ] Confirm delivery areas, minimum quantities, installation capability and project availability.
- [ ] Add current quotation and payment terms only after the owner approves them.
- [ ] Replace illustrative visuals and gallery placeholders with genuine, approved company photos; confirm permission to publish.
- [ ] Test quote form with valid and invalid input; confirm WhatsApp opens only after correct number is configured.

## Domain and hosting
- [ ] Confirm domain purchase and account ownership.
- [ ] Choose a static host and upload all website contents.
- [ ] Connect apex / `www` DNS as guided by the host.
- [ ] Confirm HTTPS certificate and canonical hostname.
- [ ] Test the 404 page on the chosen host.
- [ ] Ensure only one preferred hostname is indexable and redirect alternate hosts if supported.

## SEO fundamentals
- [ ] Check every title and meta description for final wording and uniqueness.
- [ ] Confirm canonical URLs match the actual live domain.
- [ ] Confirm `robots.txt` and `sitemap.xml` resolve over HTTPS.
- [ ] Check all internal navigation links and key page links.
- [ ] Confirm pages have a clear H1, useful content, descriptive image alt text and relevant internal links.
- [ ] Add local business schema only when genuine required business details and eligibility are confirmed.
- [ ] Search for accidental placeholder details before launch.
- [ ] Do not promise a #1 position, instant indexing or guaranteed enquiries.

## Search Console and measurement
- [ ] Verify a Domain property in Google Search Console using DNS.
- [ ] Submit the correct sitemap after domain setup.
- [ ] Inspect the homepage, key product pages and quote page.
- [ ] Check index coverage, page experience and crawl issues over time.
- [ ] Add GA4 only if needed and after privacy review.
- [ ] Track quote form starts/completions, WhatsApp clicks and call clicks without sending personal data as event values.
- [ ] Report performance using impressions, clicks, CTR, landing pages, qualified leads, quotations and orders; do not infer orders from clicks alone.

## Google Business Profile
- [ ] Create/update only the real business profile.
- [ ] Select suitable primary and secondary categories.
- [ ] Set a real address or an eligible service area according to Google's current guidelines.
- [ ] Add current opening hours, genuine contact details, website URL and authentic images.
- [ ] Ask actual clients for honest feedback; no incentives or fabricated reviews.
- [ ] Complete verification and owner access checks.

## Accessibility, performance and mobile
- [ ] Test widths 320, 375, 414, 768, 1024, 1440 and 1920 px.
- [ ] Test keyboard navigation, focus visibility, form labels and reduced-motion behavior.
- [ ] Measure Lighthouse and Core Web Vitals after the site is live; results are not pre-claimed in this package.
- [ ] Consider downloading/licensing photo assets locally to reduce external requests and improve control over image delivery.
