# कनिफनाथ कन्स्ट्रक्शन - वेबसाइट मार्गदर्शक (मराठी)

ही साधी स्टॅटिक वेबसाइट आहे (HTML, CSS, JavaScript). यासाठी सर्व्हर, डेटाबेस किंवा Firebase लागत नाही. GitHub Pages वर चालते.

> **महत्त्वाचे:** वेबसाइटवर कोणताही ईमेल, किंमत, प्रमाणपत्र, अनुभवाची वर्षे किंवा प्रकल्पांची संख्या **आम्ही स्वतःहून लिहिलेली नाही**.
> फक्त खरी माहिती भरा. माहिती नसेल तर रिकामे ठेवा - ते बटण आपोआप लपते.

---

## 1) नवीन काय आहे?

- तुमचा **मूळ लोगो** (original) हेडर आणि फूटरमध्ये पांढऱ्या प्लेटवर, हलक्या सावलीसह दिसतो.
- लोगोची मूळ artwork बदललेली नाही. फक्त display size कमी केला आहे आणि त्याच्या बाजूला **KANIFNATH CONSTRUCTION** हे नाव स्पष्ट दिसण्यासाठी जोडले आहे. लोगो ताणलेला, कापलेला किंवा बदललेला नाही - फक्त त्याच्या वरची-खालची रिकामी पांढरी जागा कमी केली आहे (`kanifnath-logo.png`). मूळ फाईल `icon-5122.png` जशीच्या तशी ठेवली आहे.
- फक्त एकच डिझाईन फाईल: `style.css`. रंग (मरून, पांढरा, फिकट राखाडी) वरच्या `:root` भागात आहेत.
- नवीन मेनू (मोबाईलवर तीन-ओळींचे बटण), "Get a Quote" बटण, नवीन फूटर - सर्व पानांवर सारखे.
- नवीन मुखपृष्ठ, सेवा-कार्ड्स, गॅलरी पान. फोटो हलके केले (29 MB वरून सुमारे 3 MB), त्यामुळे साइट जलद उघडते.
- ERP च्या स्क्रीनशॉटचे फक्त **रंग** वापरले आहेत; त्याची मांडणी (sidebar, dashboard) वापरलेली नाही.

## 2) फोन नंबर / WhatsApp / ईमेल कसे बदलायचे

`config.js` ही फाईल उघडा (Notepad चालेल). फक्त त्यातील "..." मधील मजकूर बदला:

| ओळ | काय भरायचे |
|---|---|
| `whatsappNumber` | देश कोडसह फक्त अंक, उदा. `919XXXXXXXXX` |
| `phoneDisplay`, `phoneE164` | फोन नंबर, उदा. `+91 9XXXXXXXXX` / `+919XXXXXXXXX` |
| `email` | तुम्ही रोज तपासता तो ईमेल (आत्ता रिकामा आहे) |
| `baseLocation` | उदा. `Pune, Maharashtra` |
| `businessHours` | उदा. `Mon-Sat, 9:00 am - 6:00 pm` (आत्ता `24/7` आहे - खरे असेल तरच ठेवा) |
| `logoPath` | चांगला लोगो मिळाल्यावर, उदा. `logo-new.png` (रिकामे = मूळ लोगो वापरला जातो) |

रिकामे ठेवले तर ते बटण / लिंक दिसत नाही. **पासवर्ड किंवा गुप्त कोड या फाईलमध्ये कधीही टाकू नका** - ही फाईल सार्वजनिक असते.

## 3) तुमचे स्वतःचे फोटो कसे टाकायचे

पूर्ण वेबसाइट **एकाच फोल्डरमध्ये** आहे - कोणतेही उप-फोल्डर नाहीत.

1. फोटो त्याच फोल्डरमध्ये कॉपी करा. नाव लहान अक्षरात, शब्दांमध्ये `-`, जागा (space) नको. उदा. `stone-pitching_canal-bank_001.jpg`.
2. फोटो 1600 x 1200 px आणि 400 KB पेक्षा कमी ठेवा.
3. `gallery-manifest.js` उघडा. सुरुवातीला उदाहरण दिले आहे - `items: [ ... ]` मध्ये प्रत्येक फोटोसाठी एक ओळ जोडा (`file`, `category`, `title`, `alt`).
4. फोटो आणि `gallery-manifest.js` दोन्ही GitHub वर चढवा. गॅलरी पानावर "Project photographs" मध्ये फोटो दिसतील.
5. फक्त **तुमच्या स्वतःच्या कामाचे** फोटो टाका. इंटरनेटवरचे किंवा AI चित्रे तुमचे प्रकल्प म्हणून दाखवू नका.

आत्ता साइटवर दिसणारी चित्रे "Illustration" किंवा "Reference image" म्हणून लिहिली आहेत - ती तुमच्या प्रकल्पांची आहेत असे दाखवलेले नाही.
**ती चित्रे वापरण्याचा तुम्हाला हक्क आहे का ते तपासा** (MISSING_BUSINESS_DETAILS.md पहा).

## 4) चांगला लोगो कसा टाकायचा

1. स्पष्ट लोगो (शक्यतो SVG किंवा किमान 1000 px रुंद PNG) त्याच फोल्डरमध्ये ठेवा, उदा. `logo-new.png`.
2. `config.js` मध्ये `logoPath: "logo-new.png"` लिहा.
3. हेडर आणि फूटरमध्ये नवीन लोगो आपोआप दिसेल; प्रमाण (aspect ratio) आपोआप योग्य राहते.

---

## 5) रंग बदलायचे असतील तर

`style.css` च्या सुरुवातीला `--maroon`, `--maroon-dark`, `--bg` असे रंग आहेत. तिथे बदल केला की सर्व पानांवर बदलतो.

---

## 6) GitHub वर कसे चढवायचे (थोडक्यात)

1. ZIP उघडा. आतील फोल्डरमधील **सर्व फाईल्स** (फोल्डरमध्ये उप-फोल्डर नाहीत) तुमच्या GitHub repository मध्ये "Add file -> Upload files" ने चढवा. `index.html` repository च्या सर्वात वरच्या पातळीवर असली पाहिजे.
2. नवीन साइट नीट चालते हे पाहिल्यावरच जुन्या फाईल्स (`premium-ui.css`, `enhancements.css`, नावात space असलेले जुने फोटो; `icon-5122.png` ठेवा) काढा.
3. **Settings -> Pages** मध्ये Branch निवडा, folder `/ (root)`.
4. संपूर्ण पायऱ्या `DEPLOYMENT_GUIDE.md` मध्ये आहेत.

### डोमेन (kanifnathconstruction.com) बद्दल

सर्व पानांवरील canonical लिंक, sitemap आणि robots.txt मध्ये `https://kanifnathconstruction.com` आहे. डोमेन अजून GitHub ला जोडलेले नसेल तर `DEPLOYMENT_GUIDE.md` मधील भाग 3 वाचा - चुकीचे पत्ते Google ला देऊ नका.

## 7) फॉर्म कसा चालतो?

फॉर्म काहीही साठवत नाही किंवा पाठवत नाही. ग्राहक बटण दाबल्यावर तयार संदेश दिसतो; तो ग्राहक स्वतः WhatsApp / ईमेलने पाठवतो किंवा कॉपी करतो. "पाठवले" असा खोटा संदेश कधीही दिसत नाही.
