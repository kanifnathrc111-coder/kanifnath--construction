# Image Sources, Licences & Attribution

## Images bundled in this build
The bundled gallery and hero visuals under `assets/images/` are locally authored SVG illustrations, not photographs. They have no third-party photo attribution requirement. They are visibly labelled as illustrative so they are not confused with Kanifnath Construction projects.

## Internet-image retrieval attempt
Internet-image search identified the following potentially usable Wikimedia Commons items; however, the build environment failed to resolve/download the file-host binary (`Temporary failure in name resolution`). These photos are **not included** in this website and are **not hotlinked** from pages. They are recorded for a future manual download/review option only:

1. **Gabion Wall.jpg** — author/uploader: Encik Tekateki; published under CC0 1.0 per Wikimedia Commons file page. File page: https://commons.wikimedia.org/wiki/File:Gabion_Wall.jpg
2. **Gabion Wall Example.jpg** — author: Valer Clark with Desert Landscape Conservation Cooperative; CC BY 2.0 per Wikimedia Commons file page. If reused, credit the author/source and license, and indicate modifications: https://commons.wikimedia.org/wiki/File:Gabion_Wall_Example.jpg ; license: https://creativecommons.org/licenses/by/2.0/

These are not photos of Kanifnath Construction work, and no endorsement by the image authors should be implied. Before adding any external image, revisit its source page to check the current licence and attribution instructions, download it into local `assets/images/`, record the source and author, and optimize it. Never use a found image as proof of the company's own work.

## What was intentionally not done
- No images from search-preview thumbnails were treated as source files.
- No copyrighted images from random commercial supplier pages were included.
- No remote Unsplash image hotlinks remain in the website HTML or CSS after this pass.
