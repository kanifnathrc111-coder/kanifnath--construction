## Regional keywords - needs owner confirmation
Pages contain an "Enquiries from Maharashtra and the Pune region" block marked with an HTML comment
`SERVICE-AREA BLOCK`. It only *invites* enquiries and says availability is confirmed per site. **If you do not serve
Pune/Maharashtra, delete these blocks.** Create a dedicated city page (for example "Gabion supplier in Pune") only when
you have a real office/stock/past project there to write about. Other regions: add only where you genuinely work.

## Guidance
- Never duplicate a paragraph across pages to hit a phrase.
- Do not add city names to every heading.
- Review Google Search Console "Queries" after 4-8 weeks and adjust titles using real data.
