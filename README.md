# KANIFNATH CONSTRUCTION — Premium static website

Static HTML5, CSS3 and Vanilla JavaScript website for gabion product, labour and civil construction enquiries.

## Preview locally
1. Extract the ZIP.
2. Open `kanifnath-construction-site/` in VS Code.
3. Start Live Server on `index.html`.

## Before launch
- Configure verified public contact details in `assets/js/config.js`.
- Add the official logo at `assets/images/logo.png`. The temporary KC mark is not the official logo.
- Replace illustrative/stock photos with genuine approved product and project photos; update meaningful alt text.
- Verify product specifications, offered services, service areas, manufacturer/supplier role, labour responsibilities and commercial terms.
- Follow `README-MARATHI.md`, `MISSING_BUSINESS_DETAILS.md`, `DEPLOYMENT_GUIDE.md` and `GOOGLE_SEARCH_CONSOLE_GUIDE.md`.

## Enquiry form behaviour
The static quote forms prepare a message. If a verified WhatsApp number is configured, they open WhatsApp for the visitor to review and send. Otherwise, the message is shown for copying and the page clearly says it has not been sent or saved. No backend database is included.
