# Image assets

This folder contains local illustration fallbacks, favicon and the intended location for the real company logo and approved project photography.

- `logo.png` — add the official company logo here. It is intentionally not supplied so a placeholder is not mistaken for the real logo; the header falls back to a visible KC brand-mark placeholder until the file exists.
- `gabion-illustration.svg` — illustrative gabion wall visual used as a local fallback.
- `construction-illustration.svg` — generic civil construction scene used as a local fallback.
- `engineering-pattern.svg` — decorative pattern used as a subtle brand texture.
- `favicon.svg` — site favicon.

Replace temporary/illustrative images with approved company photographs before making project claims. Keep filenames descriptive and compress real photos before uploading them.
